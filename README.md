# GeoSocial

GeoSocial — учебное Android-приложение для обмена геолокацией и отображения пользователей на интерактивной карте.

Проект состоит из мобильного приложения на React Native и серверного API на ASP.NET Core. Данные хранятся в PostgreSQL.

## Возможности

### Реализовано

- Регистрация и авторизация пользователей.
- Аутентификация с использованием JWT.
- Безопасное хранение пароля в виде хеша на сервере.
- Хранение JWT на мобильном устройстве с использованием React Native Keychain.
- Отображение интерактивной карты на основе MapLibre.
- Получение текущего местоположения устройства.
- Отправка координат на сервер.
- Получение и отображение местоположений пользователей на карте.
- Сохранение истории перемещений.
- Контейнеризация серверной части и базы данных с помощью Docker Compose.

### Планируется

- Добавление друзей и управление списком контактов.
- Геозоны и уведомления о входе и выходе из них.
- Обмен сообщениями.
- Режим невидимки.
- Улучшение обновления местоположений в реальном времени.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd geo-social-app
```

### 2. Настройка переменных окружения

В корневой папке проекта создайте файл `.env` на основе примера.

Для Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и задайте собственные значения переменных окружения, особенно пароли PostgreSQL и pgAdmin, а также секретный JWT-ключ.

Не публикуйте `.env` и не добавляйте его в Git.

### 3. Запуск backend и базы данных

Из корневой папки проекта выполните:

```bash
docker compose up -d --build
```

Команда соберёт и запустит API, PostgreSQL и pgAdmin.

Основные адреса локальных сервисов:

| Сервис                 | Адрес                                                          |
| ---------------------- | -------------------------------------------------------------- |
| Backend API            | [http://localhost:8080](http://localhost:8080)                 |
| Проверка состояния API | [http://localhost:8080/health](http://localhost:8080/health)   |
| Swagger UI             | [http://localhost:8080/swagger](http://localhost:8080/swagger) |
| pgAdmin                | [http://localhost:5050](http://localhost:5050)                 |
| PostgreSQL             | localhost:5432                                                 |

Swagger UI доступен в режиме разработки.

### 4. Запуск мобильного приложения

Перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Подключите Android-устройство с включённой USB-отладкой либо запустите эмулятор.

Запустите приложение:

```bash
npm run android
```

### 5. Подключение мобильного приложения к API

При запуске на физическом Android-устройстве необходимо указать IP-адрес компьютера в локальной сети, на котором запущен backend.

Например:

```text
http://192.168.1.100:8080
```

Устройство и компьютер должны находиться в одной локальной сети. Указанный IP — пример, используйте фактический адрес своего компьютера.

Также убедитесь, что брандмауэр разрешает входящие подключения к порту `8080`.

## API

Основные группы эндпоинтов:

| Метод | Endpoint                          | Назначение                       |
| ----- | --------------------------------- | -------------------------------- |
| POST  | `/api/auth/register`              | Регистрация пользователя         |
| POST  | `/api/auth/login`                 | Авторизация пользователя         |
| GET   | `/api/users`                      | Получение списка пользователей   |
| GET   | `/api/users/{id}`                 | Получение пользователя по ID     |
| POST  | `/api/locations`                  | Отправка текущих координат       |
| GET   | `/api/locations/current`          | Получение текущих местоположений |
| GET   | `/api/locations/history/{userId}` | Получение истории перемещений    |

Для защищённых эндпоинтов используется JWT Bearer Token.

## Хранение данных

В качестве основной базы данных используется PostgreSQL.

Entity Framework Core отвечает за взаимодействие с базой данных и применение миграций.

Docker Compose обеспечивает запуск базы данных и серверного приложения в отдельных контейнерах.

## Карты и геоданные

Для отображения карты используется MapLibre React Native.

В качестве источника картографического стиля используется OpenFreeMap:

[https://openfreemap.org/](https://openfreemap.org/)

Картографические данные основаны на OpenStreetMap и OpenMapTiles. При использовании карт необходимо сохранять предусмотренную атрибуцию источников данных.

## Безопасность

- Пароли пользователей хранятся в виде хешей.
- Защищённые API-эндпоинты используют JWT-аутентификацию.
- Токен мобильного приложения хранится с помощью React Native Keychain.
- Секреты и пароли передаются через переменные окружения.
- Файл `.env` не должен попадать в публичный репозиторий.
